1 Markerly란?

웹페이지를 보면서 무언가를 표시하거나 설명해야 할 때, Markerly는 페이지 위에 투명한 캔버스를 올려줍니다. 사이드 패널에서 도구를 고르고 웹페이지 위에 바로 그림을 그리거나 글자를 적을 수 있어요. 그린 내용은 페이지 배경과 합쳐서 PNG 한 장으로 저장되고, 필요하면 3·5·10초 간격으로 최대 10장까지 연속 캡처해 ZIP으로 묶어줍니다.

2 설치하기

Markerly는 개발자 모드에서 직접 불러와 사용할 수 있습니다. 아래 순서대로 진행해 주세요.

  1. Chrome 주소창에 chrome://extensions를 입력해 확장 프로그램 페이지를 엽니다.
  2. 오른쪽 위의 개발자 모드 스위치를 켭니다.
  3. 압축해제된 확장 프로그램을 로드합니다 버튼을 누릅니다.
  4. 다운로드한 Markerly 프로젝트 폴더를 선택합니다.
  5. 툴바의 확장 프로그램 아이콘을 누르면 사이드 패널이 열립니다.
💡

코드를 수정했거나 업데이트했나요? chrome://extensions에서 Markerly 카드의 새로고침 버튼을 누르면 변경 사항이 바로 반영됩니다.

3 핵심 사용법

3-1. 사이드 패널 열기 & 캔버스 켜기

툴바에서 Markerly 아이콘을 눌러 사이드 패널을 엽니다. 패널 오른쪽 위 토글로 현재 탭의 캔버스를 켭니다. 캔버스는 탭마다 독립적으로 작동하고, 같은 탭·같은 URL에서는 새로고침해도 그림이 자동으로 복원됩니다.

3-2. 도구 선택하기

사이드 패널의 "무엇을 할까요?" 영역에서 네 가지 동작 중 하나를 고릅니다.

도구설명추천 상황
그리기펜으로 자유 곡선을 그립니다강조 표시, 화살표, 동그라미
지우개펜과 별도 크기로 지웁니다부분 수정, 잘못 그은 선 제거
글자클릭한 위치에 텍스트를 입력하고 드래그로 이동설명 문구, 번호 매기기
페이지캔버스를 비활성화하고 웹페이지를 조작영상 재생, 스크롤, 링크 클릭

4 화면 저장하기

현재 화면을 PNG로

현재 화면 저장 버튼을 누르면, 보이는 웹페이지와 그 위에 그린 주석이 합쳐진 PNG 이미지 한 장이 다운로드 폴더에 저장됩니다. 캡처 이미지는 외부 서버로 전송하지 않고 사용자 기기에 직접 저장합니다.

연속 캡처로 ZIP 만들기

변화를 단계별로 기록하고 싶다면 연속 캡처를 사용하세요. 간격을 3초 · 5초 · 10초 중 하나로 고르고 연속 캡처 시작을 누르면, 최대 10장의 이미지를 자동으로 찍어 ZIP 파일 하나로 묶어 저장합니다.

📸

연속 캡처 중 주의사항 — 캡처가 진행되는 동안 사이드 패널을 열어두세요. 탭을 전환하거나 패널을 닫으면 캡처가 자동으로 종료되며, 그때까지 찍은 이미지를 저장합니다.

5 꿀팁 & 제한 안내

알아두면 유용한 꿀팁

⚡

오른쪽 클릭으로 전체 삭제 — 사이드 패널에서 "오른쪽 클릭으로 모두 지우기" 옵션을 켜두면, 캔버스 위에서 우클릭만으로 그림을 빠르게 초기화할 수 있습니다.

🔁

새로고침해도 그림이 유지돼요 — 같은 탭과 URL에서는 페이지를 새로고침해도 그린 내용이 자동으로 복원됩니다. 단, 탭을 닫으면 세션 데이터는 자동으로 삭제됩니다.

📁

로컬 HTML 파일에도 사용 가능 — 로컬 파일(file://)에서 사용하려면 확장 프로그램 세부정보에서 파일 URL에 대한 액세스 허용을 켜주세요.

사용할 수 없는 페이지

🚫

Chrome 내부 페이지(chrome://...)와 Chrome 웹 스토어에서는 브라우저 보안 정책상 사용할 수 없습니다. 일반 웹페이지에서 사용해 주세요.

6 개인정보 보호

Markerly는 로컬 전용 도구입니다. 그림 데이터는 브라우저 세션에만 보관되며, 캡처 이미지는 외부 서버로 전송하지 않고 사용자 기기에 직접 저장합니다. 캡처는 사용자가 버튼을 눌러 시작한 경우에만 실행됩니다.

항목처리 방식
그림 데이터브라우저 세션 저장소 (탭 닫으면 삭제)
캡처 이미지사용자 기기 다운로드 폴더에 직접 저장
외부 서버 전송없음
광고 · 제3자 추적없음
