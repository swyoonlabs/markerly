# Chrome Web Store 등록 초안

## 이름

Markerly

## 단일 목적

사용자가 현재 웹페이지 위에 시각적 주석을 그리고, 주석이 포함된 화면을 로컬 이미지로 저장하도록 돕습니다.

## 짧은 설명

웹페이지 위에 바로 그리고, 주석이 포함된 화면을 PNG 또는 연속 캡처 ZIP으로 저장하세요.

## 상세 설명

Markerly는 웹페이지를 보면서 표시하거나 설명해야 할 때 사용하는 로컬 전용 주석 도구입니다.

- 탭별 Canvas ON/OFF
- 펜 색상·굵기·불투명도 조절
- 지우개와 오른쪽 클릭 전체 삭제
- 웹페이지 조작 모드
- 현재 화면 PNG 저장
- 3초·5초·10초 간격 연속 캡처, 세션당 최대 10장을 ZIP 한 번에 저장

화면과 그림 데이터는 외부 서버로 전송되지 않습니다. 캡처는 사용자가 버튼을 눌러 시작한 경우에만 실행됩니다.

## 심사용 권한 설명

- `sidePanel`: 확장 프로그램의 주석 도구와 캡처 컨트롤을 지속적인 사이드 패널 UI로 제공합니다.
- `storage`: 펜 설정과 사용자가 만든 탭별 Canvas 선 데이터를 로컬·세션 저장소에 유지합니다.
- `tabs`: 현재 활성 탭의 제목, URL 및 탭 전환 상태를 확인합니다. 탭이 바뀌면 연속 캡처를 자동 종료합니다.
- `scripting`: 확장 프로그램을 설치하기 전에 열려 있던 페이지에도 사용자가 Canvas를 켰을 때 콘텐츠 스크립트를 주입합니다.
- `downloads`: 사용자가 요청한 PNG와 연속 캡처 ZIP 파일을 다운로드 폴더에 저장합니다.
- `<all_urls>`: 다양한 일반 웹페이지에서 동일한 주석 Canvas 기능을 제공하는 단일 목적에 필요합니다. Chrome 제한 페이지에서는 실행하지 않습니다.

## 개인정보 공개 체크 참고

- 웹사이트 콘텐츠: 처리함 — 화면 캡처와 Canvas 주석 기능에만 사용
- 웹 기록: 현재 활성 탭 URL을 기능 제공과 지원 페이지 판별에만 사용
- 데이터 판매·광고·제3자 전송: 없음
- 원격 코드: 없음

게시 전 `PRIVACY.md`를 공개 HTTPS 페이지에 게시하고 Chrome Web Store 대시보드에 해당 URL을 입력해야 합니다.
