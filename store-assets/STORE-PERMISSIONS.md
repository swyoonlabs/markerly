# Markerly 권한 설명

Chrome Web Store 개인정보 보호 항목과 심사 메모에 사용할 수 있는 권한별 설명입니다.

| 권한 | 사용 이유 |
| --- | --- |
| `sidePanel` | 웹페이지를 보면서 그리기·글자·캡처 도구를 조작할 수 있는 사이드 패널을 제공합니다. |
| `storage` | 사용자의 펜 설정과 탭별 Canvas 그림을 브라우저의 로컬·세션 저장소에 유지합니다. |
| `tabs` | 활성 탭의 제목과 URL을 표시하고, 탭이 바뀌면 연속 캡처를 자동 종료합니다. |
| `scripting` | 확장 프로그램 설치 전에 열려 있던 페이지에서 사용자가 Canvas를 켰을 때 로컬 콘텐츠 스크립트를 주입합니다. |
| `downloads` | 사용자가 요청한 단일 PNG 또는 연속 캡처 ZIP을 기기에 저장합니다. |
| `<all_urls>` | 사용자가 선택한 일반 웹페이지 위에 동일한 주석 Canvas 기능을 제공합니다. Chrome 제한 페이지에서는 실행하지 않습니다. |

Markerly는 원격 코드를 실행하지 않으며 화면·그림 데이터를 외부 서버로 전송하지 않습니다.
