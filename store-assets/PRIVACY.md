# Annotap 개인정보처리방침

최종 업데이트: 2026년 7월 19일

Annotap은 사용자가 선택한 웹페이지 위에 그림을 그리고 화면을 이미지로 저장하는 로컬 전용 Chrome 확장 프로그램입니다.

## 처리하는 데이터

- 현재 탭의 제목과 URL: 지원 가능한 페이지인지 확인하고 사이드 패널에 현재 페이지를 표시하는 데 사용합니다.
- 웹페이지 화면 콘텐츠: 사용자가 **현재 화면 저장** 또는 **연속 캡처**를 직접 실행했을 때 이미지를 생성하는 데 사용합니다.
- Canvas 그림 데이터와 도구 설정: 그림 복원 및 펜 설정 유지를 위해 브라우저의 로컬·세션 저장소에 보관합니다.

## 저장과 전송

- 모든 화면 이미지와 그림 데이터는 사용자 기기에서만 처리됩니다.
- 개발자 서버나 제3자에게 데이터를 전송하지 않습니다.
- 캡처 결과는 사용자의 다운로드 폴더에 직접 저장됩니다.
- 탭별 그림 데이터는 해당 탭을 닫으면 브라우저 세션 저장소에서 삭제됩니다.

## 데이터 공유 및 판매

사용자 데이터를 판매하거나 광고, 추적, 프로파일링 목적으로 사용하지 않으며 제3자와 공유하지 않습니다.

## 권한 사용

- `sidePanel`: 그리기 도구 UI를 표시합니다.
- `storage`: 도구 설정과 탭별 그림을 로컬에 저장합니다.
- `tabs`: 현재 활성 탭의 상태와 페이지 정보를 확인합니다.
- `scripting` 및 `<all_urls>`: 사용자가 기능을 켠 웹페이지에 Canvas를 표시합니다.
- `downloads`: 사용자가 요청한 PNG 또는 ZIP 캡처 파일을 저장합니다.

## 문의

Chrome Web Store 등록 시 이 항목을 실제 지원 이메일 또는 문의 URL로 교체해야 합니다.
