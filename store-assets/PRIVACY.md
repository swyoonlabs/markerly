# Markerly 개인정보처리방침

시행일 및 최종 업데이트: 2026년 8월 1일

Markerly는 사용자가 선택한 웹페이지 위에 그림과 글자를 추가하고 화면을 이미지로 저장하는 Chrome 확장 프로그램입니다. 아래 데이터는 기능 제공을 위해 사용자 기기 내부에서 처리되며 개발자 서버로 수집되지 않습니다.

## 처리하는 데이터

- 현재 탭의 제목과 URL: 지원 가능한 페이지인지 확인하고, 사이드 패널에 현재 페이지를 표시하며, 탭별 주석을 해당 페이지에 연결하는 데 사용합니다.
- 웹페이지 화면 콘텐츠: 사용자가 **현재 화면 저장** 또는 **연속 캡처**를 직접 실행했을 때 이미지를 생성하는 데 사용합니다.
- 사용자가 만든 Canvas 선과 글자: 같은 탭과 URL을 새로고침했을 때 주석을 복원하기 위해 브라우저 세션 저장소에 보관합니다.
- 도구 설정: 펜 색상·굵기·불투명도 등의 선택을 유지하기 위해 브라우저 로컬 저장소에 보관합니다.

## 저장과 전송

- 모든 화면 이미지와 주석 데이터는 사용자 기기에서만 처리됩니다.
- 개발자 서버나 제3자에게 데이터를 전송하지 않습니다.
- 캡처 결과는 사용자의 다운로드 폴더에 직접 저장됩니다.
- 탭별 주석 데이터는 해당 탭을 닫으면 삭제됩니다. Chrome 세션이 종료될 때에도 세션 저장소의 정책에 따라 삭제됩니다.
- 도구 설정은 확장 프로그램을 제거하거나 사용자가 Chrome의 확장 프로그램 데이터를 삭제할 때까지 보관됩니다.
- 다운로드한 PNG·ZIP 파일은 사용자가 직접 삭제할 때까지 사용자 기기에 남습니다.

## 사용자 선택과 삭제

- 캡처는 사용자가 **현재 화면 저장** 또는 **연속 캡처 시작**을 선택한 경우에만 수행됩니다.
- 사이드 패널의 전체 삭제 기능으로 현재 탭의 주석을 지울 수 있습니다.
- 탭을 닫으면 해당 탭의 주석 데이터가 삭제됩니다.
- 확장 프로그램을 제거하면 Markerly가 Chrome 저장소에 보관한 설정과 데이터가 삭제됩니다. 이미 다운로드한 파일은 사용자가 별도로 삭제해야 합니다.

## 데이터 공유 및 판매

사용자 데이터를 판매하거나 광고, 추적, 프로파일링 목적으로 사용하지 않으며 제3자와 공유하지 않습니다.

## Chrome Web Store 사용자 데이터 정책 준수

Markerly가 Chrome 확장 프로그램 권한으로 처리하는 정보는 공개된 단일 목적과 사용자 대상 기능을 제공하는 데에만 사용됩니다. Markerly의 정보 사용은 Chrome Web Store 사용자 데이터 정책의 Limited Use 요건을 준수합니다. 데이터는 광고, 신용도 판단 또는 사용자 프로파일링에 사용되지 않으며, 개발자나 다른 사람이 열람할 수 있도록 전송되지 않습니다.

## 권한 사용

- `sidePanel`: 그리기 도구 UI를 표시합니다.
- `storage`: 도구 설정과 탭별 주석을 로컬·세션 저장소에 보관합니다.
- `tabs`: 현재 활성 탭의 상태와 페이지 정보를 확인합니다.
- `scripting` 및 `<all_urls>`: 일반 웹페이지에 Canvas를 표시합니다.
- `downloads`: 사용자가 요청한 PNG 또는 ZIP 캡처 파일을 저장합니다.

## 아동의 개인정보

Markerly는 아동을 대상으로 개인정보를 수집하지 않으며, 개발자 서버로 사용자 데이터를 수집하지 않습니다.

## 방침 변경

기능 또는 데이터 처리 방식이 변경되면 이 방침의 내용과 날짜를 갱신하고 필요한 경우 확장 프로그램 내에서 사용자에게 알립니다.
